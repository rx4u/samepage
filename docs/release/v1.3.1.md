# samepage v1.3.1
<!-- headline: One line to set up -->

The Claude Code plugin now installs from a slim `plugin/` folder: only the code the plugin runs, with no tests, docs or site files (ADR-0025). This prepares the listing in Anthropic's plugin directory.

## Changes
- The marketplace installs `plugin/`. Existing `samepage@samepage` installs move to it on update.
- Hooks are written as a command plus arguments.
- Nothing changes for your store. The format is still 1.1.

## Install
- Everything: `curl -fsSL https://samepage-sigma.vercel.app/install | sh`
- Claude Code only: `/plugin marketplace add rx4u/samepage`, then `/plugin install samepage@samepage`. Already installed? Run `/plugin marketplace update samepage`, then `/plugin update samepage@samepage`.
