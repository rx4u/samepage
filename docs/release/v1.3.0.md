# samepage v1.3.0
<!-- headline: One line to set up -->

One line sets up everything. Paste it, and samepage makes your store and connects every AI tool on the machine. No questions.

```bash
curl -fsSL https://samepage-sigma.vercel.app/install | sh
```

## One-line install (new, ADR-0024)
- `install.sh` now runs `sp start` once the `sp` command is in place. The site serves the same script at `/install`.
- `sp start` asks nothing:
  - Store: reuses this machine's store; else connects or creates a private `samepage-store` repo with a signed-in GitHub CLI; else makes a local store. Run it again after `gh auth login` and the local store goes up to GitHub.
  - Profile: your name from GitHub or git, headline "Building with AI tools". Edit `profile.md` to change them.
  - Tools: Claude Code gets the plugin through its own CLI. Codex, Gemini CLI, Copilot, Cursor, Windsurf and Claude Desktop get the local MCP server, with a `.samepage-backup` of every config file it edits.
- `sp start --dry-run` prints every step and writes nothing. `SAMEPAGE_NO_START=1` installs the command only.
- The script runs only once it has downloaded completely, and it never reads your keyboard.

## Install
- Everything: `curl -fsSL https://samepage-sigma.vercel.app/install | sh`
- Claude Code only: `/plugin marketplace add rx4u/samepage`, then `/plugin install samepage@samepage`. Already installed? Run `/plugin marketplace update samepage`.
- claude.ai and Cowork: upload `samepage.skill` from this release.
