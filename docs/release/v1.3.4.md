# samepage v1.3.4
<!-- headline: One line to set up -->

The Claude Code plugin is now text only: two skills and no code (ADR-0027). They call the `sp` command from the one-line install.

## Changes
- The plugin ships no Python, hooks or MCP servers. `/sp` and the samepage skill run `~/.local/bin/sp`.
- Without `sp` installed, the skills tell you to run the one line and stop.
- Setup on GitHub and the site is down to the one line, plus a short path for claude.ai and Cowork.

## Install or update
```bash
curl -fsSL https://samepage-sigma.vercel.app/install | sh
```
