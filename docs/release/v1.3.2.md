# samepage v1.3.2
<!-- headline: One line to set up -->

The Claude Code plugin ships no hooks or shell scripts any more (ADR-0026). Context still loads at every session start for anyone who uses the one-line install: it now adds that step to your own Claude Code settings.

## Changes
- The plugin has no SessionStart or Stop hook. The end-of-session nudge is gone.
- `sp setup claude-code` (and the one-line install) adds one session-start entry to `~/.claude/settings.json`, keeps everything else, and saves a `.samepage-backup` copy.
- Plugin only, no installer? Ask "what am I working on?" or run `/sp boot`.

## Already installed?
Run the one line again. It updates the plugin and adds the session-start entry:

```bash
curl -fsSL https://samepage-sigma.vercel.app/install | sh
```
