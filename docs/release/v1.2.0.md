# samepage v1.2.0
<!-- headline: Two accounts, one page -->

Work account and personal account, same rules. Link your two stores and share what should follow you, both ways.

## Linked stores (new)
- `sp link add PATH --name personal` links a second store clone on the same machine. Up to 3 links. No tokens, no server.
- `sp sync` shares rules and decisions in both directions:
  - rules: every rule, active or paused; a pause on one side pauses the other;
  - decisions: for projects that exist in both stores, plus `general`. Decisions of a project the other store does not have stay put and are listed as skipped.
- The newer edit wins. The full list is shown before anything is written, and `--dry-run` writes nothing. Running it twice changes nothing the second time.
- Each store gets one ordinary commit through the normal write path (pull, check, index, push).
- Projects, ships, handoffs and design pointers never cross.

## Store format
Unchanged at 1.1. Synced files are copied byte for byte, so each store's Action passes as before. A record using a 1.1 key is not copied into a 1.0 store until that store is upgraded (SPEC.md, "Upgrade a store").

## Install
- Claude Code: `/plugin marketplace add rx4u/samepage`, then `/plugin install samepage@samepage`. Already installed? Run `/plugin marketplace update samepage`.
- claude.ai and Cowork: upload `samepage.skill` from this release.
- Other tools: rerun `install.sh` to get the new `sp`.
