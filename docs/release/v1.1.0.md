# samepage v1.1.0

The first release. Your AI tools forget. samepage doesn't. One shared working context for Claude, Codex, Gemini CLI, Copilot, Cursor and Windsurf, kept in a private GitHub repo of Markdown you own.

## Claude
- **Claude Code plugin.** Your context loads at session start, matched to the project you are in. `/sp log`, `/sp brief` and handoffs write small entries you confirm first.
- **claude.ai chat and Cowork skill** (`samepage.skill`, 1.1.0). It reads one boot file through the GitHub connector and writes after your yes.
- **Claude Desktop.** `sp setup claude-desktop` connects it through a local MCP server.
- **Notion stores.** Supported through the skill.

## Other coding tools (new)
- `install.sh` puts the `sp` command on your machine. No sudo, standard library Python only.
- `sp setup codex | gemini | copilot | cursor | windsurf` adds a local `samepage` MCP server to the tool's config (with a `.samepage-backup` of the old file) and a short instruction file to your project. That file holds no store content and is safe to commit.
- `sp mcp` is a local stdio MCP server with 6 read tools and 5 write tools. Every write is previewed first and needs the confirm value from that preview.
- Entries record which tool wrote them (`tool:`), and handoffs show where they came from ("via claude_ai").

## Store format 1.1
An additive change: optional `tool` and `from_tool` keys. Stores on 1.0 stay valid, and writers add the new keys only when `store.md` says 1.1. See SPEC.md, "Upgrade a store".

## Tested
See the [tool ledger](https://github.com/rx4u/samepage/blob/main/docs/build/tool-ledger.md). Tools without a passing run are marked community-tested in the README. ChatGPT is not supported in this release.

## Install
- Claude Code: `/plugin install samepage --marketplace rx4u/samepage`
- claude.ai and Cowork: upload `samepage.skill` from this release.
- Other tools: see the README, "I use another coding tool".
