# samepage v1.3.3

`/sp` is now a skill instead of a legacy command, so it also works in claude.ai and Cowork wherever plugins load. Nothing changes in how you use it.

## Changes
- `commands/sp.md` moved to `skills/sp/SKILL.md`. `/sp log`, `/sp init` and the rest work as before.
- The plugin listing has a display name, homepage, docs, support, privacy policy and terms links.

## Install
- Everything: `curl -fsSL https://samepage-sigma.vercel.app/install | sh`
- Claude Code only: `/plugin marketplace add rx4u/samepage`, then `/plugin install samepage@samepage`.
