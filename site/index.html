Get started
01Get started

One line to the same page.

Paste it into a terminal on your Mac or Linux machine. It asks nothing: it makes your private store and connects every AI tool it finds.

terminal · one line, everything
$curl -fsSL https://samepage-sigma.vercel.app/install | sh
# installs the sp command in ~/.samepage, no sudo
# makes your private samepage-store (on GitHub if the gh command is signed in)
# connects Claude Code, Codex, Gemini CLI, Copilot, Cursor, Windsurf and Claude Desktop
then ask any of them: what am I working on?

claude.ai chat and Cowork have no terminal, so they get a skill

claude.ai · cowork
Create your store (keep it Private; skip if the one line made it)
Download samepage.skill, upload it in Customize, Skills
Turn on code execution and the GitHub connector, say "set up samepage"
