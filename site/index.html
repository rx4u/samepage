what it holds

One context. Small, typed and yours.

Every entry is a short Markdown file with a few fields. You can read it, edit it by hand and diff it like code.

Projects projects/

Status, stack, links and outcomes. Every session knows what you're working on.

Decisions decisions/

Settled choices with the reason. No tool reopens a closed question.

Ships events/

What shipped, when, with links and metrics. Proof for updates and reviews.

Handoffs handoffs/

A brief left in one tool for another. Plan in chat, build in Code.

Rules rules/

How you want AI to work, everywhere or per surface. Say it once.

Design design/

Where each design system's tokens live, so design and code use the same ones.

You profile.md

Name, role and links, so every tool writes as you and not as a stranger. Plus a tiny index of boot files, so a session reads one file, not your whole store.

install

Two minutes, wherever you work.

Every path ends at the same private store, so you can add another tool later.

  1. In Claude Code, install the plugin:

    /plugin install samepage --marketplace rx4u/samepage

  2. Create your store. It asks your name, headline and up to three rules, then creates a private samepage-store repo.

    /sp init

  3. Start a new session. Your context loads on its own. Say "log this" after you ship something.

  1. Create your store in one click. Keep the name samepage-store and keep it private.

  2. Download samepage.skill. In claude.ai go to Customize, Skills, Upload a skill. Turn on code execution and the GitHub connector with access to your store.

  3. Say "set up samepage". Claude finds your store, asks who you are and writes your profile after your yes.

  1. Install the sp command. It needs git and Python 3.9 or newer, no sudo.

    git clone https://github.com/rx4u/samepage "$HOME/.samepage/tool" && sh "$HOME/.samepage/tool/install.sh"

  2. Create or connect your store.

    sp init

  3. From inside a project, connect your tool. Swap in gemini, copilot, cursor, windsurf or claude-desktop.

    sp setup codex

    It keeps a backup of every config it changes. Add --dry-run to see each change first.

  4. Restart the tool and ask "what am I working on?"

your data

Your repo. Your files. No server in between.

Private and yours

The store is a private GitHub repo you own, or a Notion page if you prefer. samepage never runs a hosted server and never sees your data.

Nothing written without your yes

Every write shows you the exact file first. In MCP tools, the server refuses any write that doesn't match the preview you saw.

Nothing deleted

Projects are archived and decisions are superseded, never removed. Your history stays.

Secrets blocked

sp check stops API keys, tokens, private keys and card numbers from ever entering a store.

Stop re-explaining your work.

Install once. Every tool starts where the last one stopped.
