The shared context layer for your AI tools.

Every AI tool keeps its own context: per app, per account, per session. samepage gives them one. Projects, decisions, shipped work and handoffs, as typed Markdown in a git repo you own.

the problem

Context is stuck where you left it.

[01] per tool

Your chat app doesn't know what your coding agent shipped.

"what did I ship this week?" gets a guess
[02] per account

Your work account doesn't know your personal one exists.

two logins, two blank slates
[03] per session

Every new session reopens a decision you already made.

Mongo again, after you picked Postgres

Memory products learn who you are inside one app. samepage moves what you're doing from one tool to the next.

how it works

Boot. Write. Hand off.

01 / boot

One read per session

Each tool reads one prebuilt boot file for its role and the repo you're in. Capped at 8,000 characters, at any store size.

02 / write

Preview, then confirm

Every write is a dry run first. The confirm token pins a hash of the preview; anything different is refused.

03 / hand off

Leave work for the next tool

A brief written in one tool opens the next session in another, stamped with where it came from.

the spec

Plain files. Typed, diffable, yours.

Flat frontmatter, one entry per file, checked by sp check on every write. Read it in any editor. Review it like code.

Decisions stay decided

The choice and the reason. Superseded, never deleted, so every tool knows what still holds.

decisions/api/2026-11-04-8d95bb8f.md
title: Postgres over Mongo
reason: row-level security per tenant
status: accepted
tool: claude_ai

Ships are proof

What shipped, when, with a link and a metric.

kind: launched
proof_url: github.com/…/pull/42
metric: p95 120 ms

Handoffs carry origin

Where it came from, where it goes, and its state.

from_tool: claude_ai
to_surface: code
status: open → done

Rules apply everywhere

Say it once. Scope it to every tool or to one role.

text: Run tests first.
scope: all

Secrets never land

Keys, tokens, private keys and card numbers are blocked before a write.

$ sp check
blocked: secret in summary
1file read per session
8,000character cap per boot file
0servers, keys or dependencies

install

Your AI tools forget. samepage doesn't.

$ git clone https://github.com/rx4u/samepage ~/.samepage/tool
$ sh ~/.samepage/tool/install.sh
samepage: installed v1.1.0
$ sp init
$ sp setup codex  # or gemini, copilot, cursor, windsurf
samepage: wrote the samepage entry in ~/.codex/config.toml
> /plugin install samepage --marketplace rx4u/samepage
> /sp init
