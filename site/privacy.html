samepage

Privacy policy

samepage is an open-source tool by Rajaraman Arumugam. It has no server and no account, so there is nothing for us to collect. This page covers the Claude plugin, the sp command, the skill and this website.

What samepage stores

Your profile (name, headline, optional links) and your work notes (projects, decisions, shipped work, handoffs, rules), as Markdown files in a store you own: a private GitHub repo, a folder on your computer, or Notion if you choose it.

Where your data goes

  • Only to your own store: git pull and git push to your own repo, using your own git login, or your own Notion workspace.
  • sp init uses your signed-in GitHub command line (gh) to create that repo. samepage never reads, stores or sends your token.
  • The AI tool you use (Claude, Codex, Gemini CLI and others) reads what samepage gives it. That tool's own privacy policy applies to it.

What we never do

  • No analytics, tracking or telemetry in the plugin, the skill or the sp command.
  • No copy of your data on any server run by us. We never see your store.
  • No selling or sharing of data, because we hold none.

This website

The site is static files hosted on Vercel, which keeps standard request logs. Fonts load from Google Fonts. The site sets no cookies; it remembers your light or dark choice in your own browser only.

Deleting your data

Delete your store repo or folder. Uninstalling samepage leaves your store untouched, so delete it yourself if you want it gone.

Children

samepage is not made for anyone under 18.
